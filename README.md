# 15577

P(15)·La(57)·N(7), 원소 칸으로 쓴 **PLaN**. (옛 이름: 블록 플래너)

공부 시간을 **블록**으로 쌓아 가는 하루 계획 웹앱. 하나의 `index.html`(HTML·CSS·JS)로 동작하며 서버 없이 브라우저에서 바로 실행됩니다.

## 주요 기능

- **타임라인 블록** – 하루 타임라인에 시간 블록을 배치·조정
- **문풀 / 인강 / 정리** – 학습 유형별 블록과 분량 기록
- **결산 · 밀도 등급** – 하루·기간별 학습 결산과 밀도 등급
- **원소 도감** – 블록이 쌓이며 모이는 원소 컬렉션
- **테마** – 화면 테마 선택
- **몰입 · 뽀모도로** – 몰입 화면과 뽀모도로 타이머
- **메모**
- **D-day** – 시험 등 목표일까지 남은 날짜

## 로컬 실행

`index.html`을 브라우저로 열면 됩니다. (빌드·설치 과정 없음)

## 데이터 옮기기

데이터는 브라우저 `localStorage`(키 `blockplanner.v1`)에 저장되므로 기기·브라우저마다 따로 보관됩니다.

1. 원래 기기에서 **결산 → 데이터 내보내기**: JSON 파일을 받고, 같은 내용이 클립보드에도 복사됩니다.
2. 새 기기에서 **결산 → 데이터 가져오기**: JSON을 붙여 넣거나 **파일 고르기**로 파일을 선택한 뒤 **이 데이터로 바꾸기**를 누릅니다.

가져오면 새 기기의 기존 기록은 가져온 데이터로 **덮어써집니다**.

## 업데이트 올리기

`index.html`의 `APP_VERSION`을 올리고 `CHANGELOG` 맨 앞에 한 줄을 추가한 뒤 `main`에 푸시합니다. 앱의 **결산 → 업데이트**에 내역이 보이고, **최신 버전 확인** 버튼이 서버의 버전과 비교해 새로고침을 안내합니다.
